1 · ¿QUÉ ES?

🔄

Una lista doble circular contiene dos enlaces por nodo y, además, el último nodo se conecta nuevamente con el primero.

Se puede avanzar y retroceder sin encontrar un final natural.

2 · ¿PARA QUÉ SIRVE?

🎯
  • Recorridos cíclicos.
  • Navegación hacia ambos lados.
  • Procesos repetitivos.
  • Sistemas de selección continua.

3 · ¿CÓMO FUNCIONA?

⚙️
  • Cada nodo conoce al anterior.
  • Cada nodo conoce al siguiente.
  • El último conecta con el primero.
  • El primero conecta con el último.

4 · USOS

🖥️
  • Reproductores de música.
  • Galerías de imágenes.
  • Menús rotativos.
  • Turnos cíclicos.
5 · ESTRUCTURA DEL NODO
NODO DOBLE CIRCULAR

anterior · dato · siguiente

La estructura del nodo puede ser la misma que en una lista doble. Lo que cambia es la forma en que se enlazan los extremos.

Estructura básica en C

struct nodo { int dato; struct nodo *anterior; struct nodo *siguiente; };

7 · ANALOGÍA · REPRODUCTOR DE MÚSICA
🎵
Canción 3 de 4
Modo repetir: después de la última canción vuelve la primera; si retrocedes desde la primera, puedes volver a la última.
Correspondencia con la lista doble circular

Canción actual → nodo actual
⏭ Siguiente → puntero siguiente
⏮ Anterior → puntero anterior
Última canción → enlaza con la primera
Primera canción → enlaza con la última

Esta analogía permite visualizar las dos características al mismo tiempo: doble enlace y circularidad.

15 · CUIDADOS IMPORTANTES

CIRCULARIDAD

El siguiente del último nodo debe apuntar al primero.

RETORNO

El anterior del primer nodo debe apuntar al último.

RECORRIDO

No busques NULL para terminar; debes detectar cuándo vuelves al nodo inicial.

ENLACES

Cada inserción o eliminación modifica enlaces en ambos sentidos.

5. Analiza el fragmento

Crear una lista doble circular de un nodo: nuevo ya está reservado.

nuevo->anterior = nuevo;
nuevo->siguiente = nuevo;
primero = ultimo = nuevo;

6. Analiza el fragmento

Eliminar un nodo intermedio en una lista doble circular de al menos tres nodos; nodo es válido.

nodo->anterior->siguiente = nodo->siguiente;
free(nodo);

7. Analiza el fragmento

Insertar al final: primero y ultimo forman una doble circular no vacía; nuevo está reservado.

nuevo->anterior = ultimo;
nuevo->siguiente = primero;
ultimo->siguiente = nuevo;
primero->anterior = nuevo;
ultimo = nuevo;

💡
EN RESUMEN
Una lista doble circular combina dos ideas: puedes avanzar o retroceder y, además, el recorrido nunca termina de forma natural. Un reproductor de música en modo repetir o una galería de imágenes continua son analogías ideales: después del último elemento vuelves al primero y también puedes desplazarte en sentido contrario.
