Primero: ¿cola con prioridad o montículo?

🎫

Cola con prioridad

Es una estructura donde cada elemento tiene una prioridad. El elemento con mayor prioridad se atiende antes, aunque haya llegado después.

⚡

Montículo (Heap)

Es un árbol binario completo que mantiene el elemento de mayor o menor prioridad en la raíz. Por eso resulta muy útil para implementar colas con prioridad.

🧠

Idea para recordar

Cola con prioridad describe qué debe ocurrir. Heap describe una manera eficiente de organizar los datos para lograrlo.

MONTÍCULOS · IDEA CLAVE
En un Max-Heap el mayor valor permanece en la raíz. En un Min-Heap permanece el menor. Al insertar se aplica subir (sift-up) y al extraer se aplica bajar (sift-down).
