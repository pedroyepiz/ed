1 · ¿QUÉ ES?

🔄

Lista enlazada donde el último nodo vuelve a enlazarse con el primero.

No existe un NULL natural al final.

2 · ¿PARA QUÉ SIRVE?

🎯
  • Procesos repetitivos.
  • Turnos cíclicos.
  • Recorridos continuos.
  • Recursos rotativos.

3 · ¿CÓMO FUNCIONA?

⚙️
  • Se parte de CABEZA.
  • Cada nodo apunta al siguiente.
  • El último vuelve a CABEZA.

4 · USOS

🖥️
  • Round Robin.
  • Turnos de jugadores.
  • Playlists.
  • Buffers circulares.

Turnos de jugadoresDespués del último jugador vuelve a iniciar el primero.

11 · CUIDADOS IMPORTANTES

RECORRIDO

No debes esperar encontrar NULL. El recorrido termina cuando vuelves al nodo inicial.

LISTA VACÍA

Verifica siempre si CABEZA es nula antes de recorrer.

ENLACES

Al insertar o eliminar, conserva el enlace entre el último nodo y CABEZA.

BUCLES

Una condición incorrecta puede provocar un ciclo infinito.

5. Analiza el fragmento

Crear una lista circular simple de un nodo: nuevo ya está reservado.

nuevo->siguiente = nuevo;
cabeza = nuevo;

6. Analiza el fragmento

Recorrer: cabeza apunta a una lista circular simple no vacía.

struct nodo *aux = cabeza;
while (aux != NULL) {
    printf("%d ", aux->dato);
    aux = aux->siguiente;
}

7. Analiza el fragmento

Insertar al final: primero y ultimo forman una circular no vacía; nuevo está reservado.

nuevo->siguiente = primero;
ultimo->siguiente = nuevo;

💡
EN RESUMEN
Una lista circular es una estructura donde el último nodo regresa al primero. Es ideal para procesos repetitivos, sistemas por turnos y recorridos cíclicos. La ruleta de casino ayuda a visualizar que no existe un final definitivo: después de una vuelta, el recorrido comienza nuevamente.
