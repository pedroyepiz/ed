1 · ¿QUÉ ES?

↔️

Una lista doble es una estructura dinámica en la que cada nodo tiene dos enlaces.

anterior ← nodo → siguiente

2 · ¿PARA QUÉ SIRVE?

🎯
  • Recorrer en ambos sentidos.
  • Retroceder y avanzar.
  • Facilitar ciertas eliminaciones.
  • Modelar historiales.

3 · ¿CÓMO FUNCIONA?

⚙️
  • Cada nodo conoce al anterior.
  • Cada nodo conoce al siguiente.
  • PRIMERO marca el inicio.
  • ULTIMO marca el final.

4 · USOS

🖥️
  • Historial del navegador.
  • Undo / Redo.
  • Reproductores.
  • Galerías de imágenes.
5 · ESTRUCTURA DEL NODO
NODO DOBLE

anterior · dato · siguiente

El puntero anterior permite regresar; el puntero siguiente permite avanzar.

Estructura básica en C

struct nodo { int dato; struct nodo *anterior; struct nodo *siguiente; };

14 · CUIDADOS IMPORTANTES

PRIMERO

El primer nodo debe tener anterior = NULL.

ULTIMO

El último nodo debe tener siguiente = NULL.

DOS ENLACES

Revisa siempre anterior y siguiente al insertar o eliminar.

MEMORIA

Libera la memoria del nodo cuando sea eliminado.
💡
EN RESUMEN
Una lista doble permite recorrer los datos en ambos sentidos. Su mejor analogía es el historial de un navegador: puedes ir hacia atrás con Anterior y volver hacia adelante con Siguiente.
