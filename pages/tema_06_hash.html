1 · ¿Qué es una tabla hash?

Una tabla hash utiliza una función que transforma una clave en una posición de almacenamiento. La meta es localizar un dato a partir de su clave sin recorrer toda la colección.

Dos claves pueden generar la misma posición: eso se llama colisión y requiere una estrategia de resolución.

3 · ¿Cómo funciona?

Para una tabla de siete posiciones, utiliza como ejemplo h(clave) = clave % 7. Las claves 10 y 17 van inicialmente a la posición 3; por eso existe una colisión.

10 % 7 = 317 % 7 = 3Colisión en 3

Encadenamiento: cada posición guarda una lista de claves. Direccionamiento abierto: busca otra posición siguiendo una regla, por ejemplo sondeo lineal.

4 · Implementación

// Ejemplo educativo para claves enteras no negativas:
size_t indice(unsigned clave, size_t capacidad) {
    return clave % capacidad;
}

El factor de carga es elementos / posiciones. En condiciones favorables, buscar o insertar suele acercarse a O(1) promedio; con muchas colisiones puede empeorar. Una función de ejemplo como módulo no es una función hash criptográfica.

5 · Problema guiado

Con siete posiciones, calcula el índice de 10, 17, 24, 31 y 12. Resuelve las colisiones mediante encadenamiento y luego con sondeo lineal. Compara cuántas posiciones se revisan al buscar 31.

6 · Resumen

Una buena tabla hash combina función de dispersión, capacidad adecuada y una estrategia de colisiones. Para archivos indexados, el índice debe guardar una referencia fiable al registro y actualizarse cuando cambie el archivo.
